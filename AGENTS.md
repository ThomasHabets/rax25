## General

* One logical change per commit
* Do not vendor dependencies
* Keep `SPEC_DIFFERENCES.md` up to date with differences between specs, and
  where the spec and implementation differ
* Commit with env `SLOW=true` to include direwolf interop tests

## Commit messages

* Max 72 characters per line, for both first line and body
* First line short description
* Further commit message elaborates on why with examples where possible

## Presubmits

NEVER skip presubmits.
